# Tino MCP: five authenticated read-only positive cases

This 70-second video assembles seven screenshots from real authenticated tests on 20 October 2026. It is a screenshot walkthrough, not a continuous screen recording. The five cases show services and renewal dates, VPS details with credentials omitted, domain nameservers, DNS records across three screenshots, and unpaid invoices.

The original UI text is preserved. Case labels appear in a separate 180-pixel band outside the UI image and are burned into the video, so they remain visible without subtitle support. The MP4 also includes a default English mov_text subtitle track. There is no audio or narration.

This video includes only the five positive read-only cases. It does not claim that all operations or safety cases passed. The earlier video, failed-case evidence, screenshots, script and reports remain unchanged in the separate local evidence directory; they are not part of this positive-only artifact.

Service cancellation is handled by the customer in the Tino client dashboard and is outside this MCP demonstration. The reviewed screenshots show no passwords, access tokens or private keys. The DKIM p= value is a public key.
